# 插件使用指南

了解如何在 MicYou 中安裝、管理、設定插件，以及使用音效板與手機跨端同步功能。

## 安裝插件

### 方式一：從插件市集安裝（推薦）

1. 開啟 MicYou 桌面端，進入 **設定 → 插件**。
2. 點擊「插件市集」瀏覽官方與社群插件。
3. 在目標插件資訊卡上點擊「安裝」。
4. 查閱插件請求的權限清單與能力宣告，點擊確認後即可自動下載並完成安裝。

### 方式二：手動安裝（離線 / 本地開發）

插件可直接以資料夾或 `.zip` 壓縮檔形式匯入：

1. 進入 **設定 → 插件** 頁面。
2. 點擊「開啟插件目錄」，系統將自動開啟本地存放路徑：
   - **Windows**：`%APPDATA%\micyou\plugins\`
   - **macOS / Linux**：`~/.config/micyou/plugins/`
3. 將解壓縮後的插件資料夾放入該目錄（每個插件單獨存放在以其 ID 命名的子資料夾內）。
4. 返回設定頁面點擊「重新整理」即可辨識。

> [!NOTE] 權限安全檢查
> 無論是從市集下載還是手動匯入 ZIP 檔，MicYou 都會在首次載入前展示權限清單（如麥克風音訊流存取、網路請求等），經使用者確認授權後才會執行。

## 管理與設定插件

在插件管理清單中，你可以對每個插件進行以下操作：

- **啟用 / 停用**：透過資訊卡右側的開關隨時啟停插件。啟用後音訊 DSP 節點將即時接入處理鏈。
- **參數設定**：點擊資訊卡上的「設定」圖示：
  - 若插件宣告了視覺化表單（`configSchema`），可以直接使用原生滑桿、開關和下拉選單修改。
  - 若未宣告表单，可在內建編輯器中直接修改 JSON 設定檔。
- **檢視執行記錄**：點擊「日誌」檢視該插件獨立的控制台輸出（記憶體環形緩衝區，保留最新 500 行），便於定位異常。
- **檢查更新**：若插件支援線上更新，點擊資訊卡上的「檢查更新」可一鍵升級至最新版本並平滑重新載入。
- **解除安裝**：點擊刪除圖示即可停用並清理該插件的本地檔案。

## 專屬設定面板

部分功能複雜的插件（宣告了 `ui.panels`）會在設定視窗側邊欄產生專屬設定頁面。該頁面在安全獨立的沙箱中運作，並提供專屬的視覺化操作介面。

## 音效板（Soundpad）功能

音效板類插件啟用後，主介面將展示可自訂的音效按鈕網格：

- 點擊按鈕或按下綁定的全域快捷鍵即可觸發音訊播放。
- 播放的聲音會自動混入虛擬麥克風輸出通道，語音通話對端和本地喇叭均能同步聽到。
- 支援在插件設定中自訂音訊檔案對應。

## 全域快捷鍵

支援全域快捷鍵的插件可以在系統背景或全螢幕遊戲執行期間隨時回應熱鍵操作（如一鍵靜音、播放指定音效等）。

> [!NOTE] Linux 桌面環境說明
> 全域快捷鍵原生支援 Windows、macOS 以及 Linux X11 工作階段。在 Wayland 工作階段下由於視窗合成器安全隔離，建議使用介面按鈕操作。

## 手機與電腦跨端同步

當手機端與電腦端 MicYou 建立連線後，兩端的插件訊息匯流排會自動互通：

- 手機端感測器插件採集的資料（如晃動、電量等）可即時發送至電腦端插件處理。
- 電腦端插件也可以向手機發送控制指令。
- 跨端通訊狀態會即時顯示在插件面板右上角。

## 常見問題

### 插件提示載入失敗？
- 檢查作業系統平台與 CPU 架構是否相符（例如 x86_64、arm64）。
- 確認插件清單中宣告的 `apiVersion` 是否與目前 MicYou 宿主版本一致。

### 啟用 DSP 插件後聲音卡頓或爆音？
- 即時音訊處理對效能有嚴格要求。如果在主音訊處理函式中執行了耗時 I/O 或大記憶體配置，會導致音訊掉幀。請先停用該插件，並在插件日誌中排查效能瓶頸。
