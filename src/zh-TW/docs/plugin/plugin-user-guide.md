# 插件使用者指南

面向 MicYou 使用者的插件使用說明：安裝、解除安裝、GUI 管理、設定與跨端同步。

## 安裝插件

### 從插件市集安裝（推薦）

1. 進入 **設定 → 插件**，點擊「插件市集」按鈕瀏覽官方與社群插件。
2. 在感興趣的插件資訊卡上點擊「安裝」。
3. 系統將抓取遠端 manifest 呈現所需權限與能力清單，確認後自動下載並完成安裝。
4. 安裝完成後插件狀態將變更為「已安裝」，並在本地插件清單中立即可用。

### 手動安裝（離線 / 開發者模式）

插件分發包含**插件目錄**（含 `plugin.json` 與進入點檔案）與 **ZIP 壓縮檔**：

1. 開啟應用程式，進入 **設定 → 插件** 頁面。
2. 點擊「開啟插件目錄」定位宿主插件存放路徑：
   - **Linux / macOS**：`~/.config/micyou/plugins/`
   - **Windows**：`%APPDATA%\micyou\plugins\`
3. 將解壓縮後的插件資料夾放入該目錄（每個插件單獨一個子目錄）。
4. 返回插件設定頁面點擊「重新整理」。

> **提示**：手動匯入 ZIP 壓縮檔時，系統會自動解析並展示權限清單（請求的能力、作者、授權等），經使用者確認後方可載入。

## 解除安裝插件

- 在插件清單中點擊垃圾桶圖示確認解除安裝，插件將被停用並從磁碟中刪除。
- 也可以直接在作業系統的插件目錄中手動刪除對應的插件資料夾，重新整理後生效。

## 在 GUI 中管理插件

| 操作 | 說明 |
| --- | --- |
| **啟用 / 停用** | 資訊卡右側開關（啟用時即刻載入執行階段並接入 DSP 鏈路） |
| **解除安裝** | 移除插件並清理本地檔案 |
| **檢視日誌** | 檢視該插件獨立的環形日誌輸出（最多保留 500 行） |
| **編輯設定** | 彈出設定編輯器，儲存後寫入本地持久化儲存 |
| **跨端狀態** | 檢視與行動裝置端的插件訊息同步連通狀態 |

## 插件專屬設定頁

宣告了 `ui.panels` 的插件，會在設定對話方塊的側邊欄動態新增專屬設定面板。頁面由插件自帶的自包含 HTML 在沙箱中渲染，支援與宿主雙向通訊。

## 全域快捷鍵

支援註冊系統全域快捷鍵的插件（如 Soundpad），在應用處於背景或全螢幕遊戲狀態下依然能回應熱鍵動作。

## 音效板（Soundpad 類插件）

- 啟用音效板類插件後，主介面將展示音效網格按鈕。
- 點擊按鈕即可觸發音訊混音播放，音效將直接混入虛擬麥克風通道，通話對端與本地均可收聽。
- 使用者可直接在插件設定中增減音訊檔案對應。

## 更新插件

若插件在 Manifest 中宣告了 `updateUrl`，可在插件資訊卡中點擊「檢查更新」。發現新版本後可一鍵下載更新並平滑重新載入。

## 設定插件參數

1. 開啟插件面板，點擊對應資訊卡的設定圖示。
2. 在編輯器中按需求修改 JSON 設定，例如：

```json
{ "gain": 2.0, "threshold": -40.0 }
```

3. 點擊「儲存」即可生效（部分即時 DSP 插件可能需要重新啟用一次以使底層演算法重新初始化）。

## 跨端插件同步

當手機（Android 客戶端）與電腦建立連線後，兩端的插件系統自動互通：

- 手機插件與電腦插件透過同一訊息協定（`PluginMessage`）互發訊息。
- 電脑插件可用 `message.send` 定向至 `remote` 目標（如手機上的感測器插件）。
- 手機插件採集的資料（感測器、電池等）可即時推給電腦插件處理，處理後結果回傳。
- 跨端狀態在插件面板右上角顯示。
