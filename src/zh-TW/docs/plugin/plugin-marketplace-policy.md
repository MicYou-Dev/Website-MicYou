# 插件市集規範與准入政策

本文件說明了發布至 MicYou 官方插件市集的規範要求、開源授權條款政策與安全審核流程。

## 1. 授權條款政策與插件例外條款

MicYou 專案主程式碼採用 GNU GPLv3 授權條款，並附加官方插件例外條款（**MicYou Plugin Exception v1.0**）。

### 1.1 豁免範圍
- 插件開發者透過 MicYou 官方提供的 Plugin API 與 Host API 開發獨立插件時，**不受 GPLv3 授權條款的傳染性約束**。
- 非商業用途的獨立插件可以自由選擇寬鬆開源授權條款（如 MIT、Apache-2.0、BSD）或閉源私有授權條款。

### 1.2 商業化政策
- 任何透過 MicYou 插件進行付費銷售、商業訂閱或商業分發的行為，需事先取得 MicYou 專案版權方的書面授權或許可。
- 企業內部自用且不對外公開發布分發的工具插件不受此商業許可限制。

## 2. 官方插件市集准入要求

提交至官方插件市集（MicYou Plugin Marketplace）的插件需滿足以下條件之一：

1. **開源准入**：插件原始碼完全公開，且採用與主流生態相容的自由/開源授權條款（如 MIT、Apache-2.0、GPL-3.0 等）。
2. **審查准入**：閉源或特定商業插件需通過官方安全團隊的合規性與程式碼安全性審查。

### 本地化展示建議

市集根據使用者客戶端語言自動展示插件資訊：
- 在 `plugin.json` 中設定 `nameI18n` 和 `descriptionI18n`（依 BCP-47 語言標籤對應）。
- 提交至官方市集的插件建議至少提供繁體中文（`zh-TW` 或 `zh-CN`）與英文（`en`）兩種語言描述。

## 3. 安全與隱私規範

- **權限最小化原則**：插件僅能申請其實際功能所必需的 capabilities 權限，嚴禁過度申請敏感權限。
- **音訊隱私與資料安全**：嚴禁在未經使用者明確知情與同意的情況下上傳、記錄或竊取使用者麥克風音訊流及系統剪貼簿內容。
- **檔案沙箱約束**：檔案讀寫必須限定在宿主分配的插件私有目錄內，禁止試圖穿透沙箱。
- **嚴禁惡意程式碼**：嚴禁包含任何挖礦、後門、木馬、外掛注入或破壞宿主系統穩定性的行為。

## 4. 提交審核流程

1. 開發者在自身 GitHub 儲存庫完成插件開發並透過 CI 編譯打包，將產物發布至 GitHub Release。
2. Fork 官方市集索引儲存庫（[MicYou-Plugins](https://github.com/MicYou-Dev/MicYou-Plugins)），在 `plugin/<plugin-id>/` 目錄下新增 `plugin.json` 與安裝套件下載連結。
3. 提交 Pull Request，觸發自動化 CI 流水線對清單格式、簽章與能力宣告進行語法校驗。
4. 官方審核團隊進行安全與合規審查，確認通過後合併並同步至線上市集索引。
