# 插件使用指南

了解如何在 MicYou 中安装、管理、配置插件，以及使用音效板与手机跨端同步功能。

## 安装插件

### 方式一：从插件市场安装（推荐）

1. 打开 MicYou 桌面端，进入 **设置 → 插件**。
2. 点击「插件市场」浏览官方与社区插件。
3. 在目标插件卡片上点击「安装」。
4. 查阅插件请求的权限列表与能力声明，点击确认后即可自动下载并完成安装。

### 方式二：手动安装（离线 / 本地开发）

插件可直接以文件夹或 `.zip` 压缩包形式导入：

1. 进入 **设置 → 插件** 页面。
2. 点击「打开插件目录」，系统将自动打开本地存放路径：
   - **Windows**：`%APPDATA%\micyou\plugins\`
   - **macOS / Linux**：`~/.config/micyou/plugins/`
3. 将解压后的插件文件夹放入该目录（每个插件单独存放在以其 ID 命名的子文件夹内）。
4. 返回设置页面点击「刷新」即可识别。

> [!NOTE] 权限安全检查
> 无论是从市场下载还是手动导入 ZIP 包，MicYou 都会在首次加载前展示权限清单（如麦克风音频流访问、网络请求等），经用户确认授权后才会执行。

## 管理与配置插件

在插件管理列表中，你可以对每个插件进行以下操作：

- **启用 / 禁用**：通过卡片右侧的开关随时启停插件。启用后音频 DSP 节点将即时接入处理链。
- **参数配置**：点击卡片上的「设置」图标：
  - 若插件声明了可视化表单（`configSchema`），可以直接使用原生滑块、开关和下拉框修改。
  - 若未声明表单，可在内置编辑器中直接修改 JSON 配置文件。
- **查看运行日志**：点击「日志」查看该插件独立的控制台输出（内存环形缓冲区，保留最新 500 行），便于定位异常。
- **检查更新**：若插件支持在线更新，点击卡片上的「检查更新」可一键升级至最新版本并平滑重载。
- **卸载**：点击删除图标即可禁用并清理该插件的本地文件。

## 专属设置面板

部分功能复杂的插件（声明了 `ui.panels`）会在设置窗口侧边栏生成专属设置页面。该页面在安全的独立沙箱中运行，并提供专属的可视化操作界面。

## 音效板（Soundpad）功能

音效板类插件启用后，主界面将展示可自定义的音效按钮网格：

- 点击按钮或按下绑定的全局快捷键即可触发音频播放。
- 播放的声音会自动混入虚拟麦克风输出通道，语音通话对端和本地扬声器均能同步听到。
- 支持在插件配置中自定义音频文件映射。

## 全局快捷键

支持全局快捷键的插件可以在系统后台或全屏游戏运行期间随时响应热键操作（如一键静音、播放指定音效等）。

> [!NOTE] Linux 桌面环境说明
> 全局快捷键原生支持 Windows、macOS 以及 Linux X11 会话。在 Wayland 会话下由于窗口合成器安全隔离，建议使用界面按钮操作。

## 手机与电脑跨端同步

当手机端与电脑端 MicYou 建立连接后，两端的插件消息总线会自动互通：

- 手机端传感器插件采集的数据（如晃动、电量等）可实时发送至电脑端插件处理。
- 电脑端插件也可以向手机发送控制指令。
- 跨端通信状态会实时显示在插件面板右上角。

## 常见问题

### 插件提示加载失败？
- 检查操作系统平台与 CPU 架构是否匹配（例如 x86_64、arm64）。
- 确认插件清单中声明的 `apiVersion` 是否与当前 MicYou 宿主版本一致。

### 启用 DSP 插件后声音卡顿或爆音？
- 实时音频处理对性能有严格要求。如果在主音频处理函数中执行了耗时 I/O 或大内存分配，会导致音频帧掉落。请先禁用该插件，并在插件日志中排查性能瓶颈。
